# SmartCAB-Change-Management-Automation-Workflow

SmartCAB automates key change-management activities through two Power Automate workflows integrated with JIRA and Excel.

Workflow 1: Change Request Validation & Notifications

Evaluates change-request tickets against required-field criteria and sends email notifications to the responsible owners when mandatory information is missing.

Workflow 2: Scheduled Ticket Reporting

Refreshes an Excel tracking sheet with ticket information retrieved from JIRA every five minutes, keeping the report up to date.

Technology Stack

* Microsoft Power Automate
* JIRA REST APIs and JQL
* Microsoft Excel
* Postman for API testing

This repository contains workflow diagrams and supporting screenshots illustrating the automation logic, API integration, validation conditions, email notifications, and scheduled reporting process.
